# Reference — 结构化学习

## 1. 知网 vs 堆积

- **堆积**：按表面特征记步骤，知识点彼此无路（知识孤岛）。
- **知网**：用底层原理连接；一个新场景用已有原理推演。
- **理解三问**（每条新知识）：
  1. 来龙去脉：为何出现、如何演进？
  2. 至少与哪 3 条已有知识相关？
  3. 什么场景适用 / 不适用？

## 2. 学习 ≈ 新习惯（赫布：一起激活的连接变强）

| 阶段 | 要点 |
|------|------|
| 最简应用 | 问「知道什么就够做第一步」；立刻最小场景跑通 |
| 刻意练习 | 单点突破薄弱处 + 及时反馈 + 略超当前能力 |
| 自然重复 | 模板/checklist 嵌入工作流；每次重复加一个改进点 |

## 3. 知识迁移

- **近迁移**：相似任务，复用流程框架，改细节。
- **远迁移**：抽一般规律（分析、对齐、决策、协作等）到新领域。
- **结构化三步**：搭框架 → 按原理分层抽象（流程 / 原理 / 目标）→ 举一反三多场景验证并记录失效边界。

## 4. 四遍学习

| 遍 | 目标 |
|----|------|
| 1 | 认路：讲什么、核心问题、哪里不懂 |
| 2 | 理解：概念连起来，作者论证链 |
| 3 | 关联：挂到已有体系 |
| 4 | 提取：合上材料 — 费曼、反例、真实用一次 |

主动提取 + **间隔**（欲长期记住则逐渐拉长间隔）优于连续重读。

## 5. 个人体系三层

1. **认知框架**：先问「这是什么类型的问题」，用原理组织框架。
2. **方法流程**：过程沉淀（进行中填框架），非事后硬憋总结。
3. **知识体系**：对外结构化 + 显性化经验 + 对内内化 + 指导行动。

**四动作**：结构化信息 → 显性化经验（「这次什么方法有效」）→ 内化（严格套用一次、用自己的话讲、真实场景调用）→ 行动（岗位目录 + **可迁移**核心库）。

**Obsidian 建议目录**

```
可迁移/          # 换岗仍成立的方法论
岗位-当前角色/    # 岗位专用技能与知识
learning-notes/  # 本 skill 默认输出
```

## 6. 系统性思维（搭体系三性）

- **整体性**：知识指向同一目标，非零件堆叠。
- **调整性**：目标受阻时改框架，非死守。
- **转换性**：根本目标变化时，框架可迁移复用。

碎片化学习：**碎片化输入，体系化沉淀** — 先提炼「解决什么问题」，再归位。

## 7. 元认知四步

1. 评估内容难度与大致时间（浏览结构，标难点与可快扫部分）。
2. 评估自身起点与动机（先前知识、差距）。
3. 选策略组合：重复 / 深加工 / 组织 / 监控（见下）。
4. 过程监控点：小段自测，无效则换策略。

**四策略**：重复（熟练自动化）、深加工（类比/自解释）、组织（分类/框架）、监控（觉察懂/不懂）。

## 8. 零级原理 → 知识树

- **零级原理**：领域内解释面广、难再拆的底层句。
- 树：零级（根）→ 一级（关键环节）→ 二级（具体方法）→ 案例。
- 新概念只问：挂在哪条原理、哪根枝？

## 9. AI 时代结构

1. 碎片资料 → 归纳 3–5 条原理（用户核实，非盲信）。
2. 按原理建 2–3 级结构 + 应用场景。
3. 解决问题时**用结构提问**；AI 填材料，用户保判断。

术语别名（同一机制）：组块化、认知负荷、图示/schema — 优先按**原理**统一，不按名词收藏。
